# Phase C: Budget Management - User Guide

## 🎯 Quick Start Guide

Welcome to Budget Management! This guide will help you set up and manage your budgets effectively.

## 📱 Accessing Budgets

### Method 1: Sidebar Navigation
1. Look for the **"Budgets"** link in the left sidebar
2. Icon: 🎯 Target icon
3. Click to open the Budgets page

### Method 2: Dashboard Widget
1. Scroll to the right column on Dashboard
2. Find the **"Budget Overview"** widget
3. Click **"View All"** or **"Manage"** link

## 🆕 Creating Your First Budget

### Step 1: Open Create Modal
- Click the **"Create Budget"** button (top right)
- Purple gradient button with + icon

### Step 2: Choose Budget Type

#### Option A: Overall Budget
- Tracks **all expenses** across all categories
- Good for: Monthly spending limit
- Example: "I want to spend max $2,000 this month"

**Steps:**
1. Click **"Overall"** button
2. Enter amount (e.g., 2000)
3. Select period dates
4. Click **"Create Budget"**

#### Option B: Category Budget
- Tracks expenses in a **specific category**
- Good for: Controlling spending in one area
- Example: "I want to spend max $500 on Food this month"

**Steps:**
1. Click **"Category"** button
2. Select category from dropdown (Food, Transport, etc.)
3. Enter amount (e.g., 500)
4. Select period dates
5. Click **"Create Budget"**

### Step 3: Set Period
- **Default**: Current month (auto-filled)
- **Custom**: Choose any start and end dates
- **Tip**: Most users use monthly budgets

### Step 4: Confirm
- Review your budget details
- Click **"Create Budget"**
- Success! Your budget is now active

## 📊 Understanding Budget Status

### Status Colors

#### 🟢 Green - Safe
- **Utilization**: Less than 80%
- **Meaning**: You're doing great! Plenty of budget left
- **Example**: Spent $400 of $1,000 (40%)

#### 🟡 Yellow - Warning
- **Utilization**: 80% to 100%
- **Meaning**: Approaching your limit, be careful
- **Example**: Spent $850 of $1,000 (85%)

#### 🔴 Red - Exceeded
- **Utilization**: Over 100%
- **Meaning**: You've exceeded your budget!
- **Example**: Spent $1,200 of $1,000 (120%)

### Progress Bar
```

$800 spent | 80% | $1,000 total
```

## 🔔 Budget Alerts

### When Do Alerts Appear?

1. **Warning Alert** (Yellow)
   - Triggers at 80% utilization
   - Message: "You've used 80% of your budget"
   - Action: Consider reducing spending

2. **Exceeded Alert** (Red)
   - Triggers at 100% utilization
   - Message: "Budget exceeded!"
   - Action: Review expenses, adjust budget

### Where to See Alerts?

1. **Budgets Page**
   - Red/orange banner at top
   - Lists all exceeded/warning budgets
   - Shows utilization percentage

2. **Dashboard Widget**
   - Exceeded budgets shown first
   - Warning icon displayed
   - Quick overview of status

3. **Stats Cards**
   - "Warnings" card shows count
   - "Exceeded" card shows count
   - Click to filter

## ✏️ Editing a Budget

### When to Edit?
- Budget amount was too low/high
- Need to extend period
- Want to change category

### How to Edit?
1. Find the budget card
2. Click the **Edit icon** (pencil) in top-right
3. Modify fields as needed
4. Click **"Update Budget"**
5. Status recalculates automatically

### What Can You Edit?
- ✅ Budget amount
- ✅ Period dates
- ✅ Budget type (overall ↔ category)
- ✅ Category (for category budgets)

---

## 🗑️ Deleting a Budget

### When to Delete?
- Budget no longer needed
- Created by mistake
- Want to start fresh

### How to Delete?
1. Find the budget card
2. Click the **Delete icon** (trash) in top-right
3. Confirm deletion in modal
4. Budget removed immediately

### ⚠️ Warning
- Deletion is **permanent**
- Cannot be undone
- Historical data is lost

## 🔍 Filtering Budgets

### Filter by Type
- **All Types**: Show everything
- **Overall**: Only overall budgets
- **Category**: Only category budgets

### Filter by Status
- **All Status**: Show everything
- **Active Only**: Only current period budgets
- **Warning**: Only 80-100% utilization
- **Exceeded**: Only over 100% utilization

### How to Filter?
1. Look for filter dropdowns below stats cards
2. Select desired filter
3. Budget list updates instantly

## 🔧 Troubleshooting

### Budget Not Showing?
- Check if period is active (today within start/end)
- Use "All Status" filter
- Refresh page

### Wrong Spent Amount?
- Spent amount calculated from expenses
- Check expense dates match budget period
- Verify expense category (for category budgets)

### Can't Create Budget?
- Check for duplicate (same type/category/period)
- Verify amount is positive
- Ensure period end is after start

### Progress Bar Not Updating?
- Refresh page
- Check if expenses were added
- Verify expense dates

```
├── Transport Budget ($300)
└── Entertainment ($200)
```

- Start with current spending
- Reduce by 10% each month

- Warning: Time to slow down
- Exceeded: Review and adjust
- Don't ignore alerts!

### Tip 5: Seasonal Budgets
- Higher in December (holidays)
- Lower in January (recovery)
- Adjust for vacations
